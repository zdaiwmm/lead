LEAD / HOW IT WORKS

从产品目标，持续推进到可核实的结果

本机 Codex 根据实际证据研究、规划和执行，Lead 保存原任务、账号与真实结果。研究、内容和不同账号可以独立运行；需要同一份产物的工作才等待它。

连接本人已登录的 Codex

在项目中连接本机设备，复用你自己的 Codex 登录，无需另配模型 API key。设备负责完整执行和会话续接；Lead 保留任务调度、账号归属与发送记录。关闭网页后后台继续，电脑休眠、关机或离线时等待原设备恢复。

↓ 保留原项目与账号资料

提供产品介绍与目标

先理解产品的核心价值、适合的人群与证据。没有登录账号，也可以开始调查。

连接渠道账号

可一次提供本次登录信息，也可先检查已有登录状态。平台在原窗口核对真实身份，遇验证码、扫码或设备确认等必要步骤再请你接手。第三方登录完成后，回到原站重新核对身份。嵌入来源需确认时会显示具体网站，仅临时读取公开内容。关闭窗口后继续核对；取消连接会结束本次尝试并清除登录信息。

↓ 独立准备，有证据后继续

一个经营判断入口

Codex 使用产品资料、实时调查、已有结果和适用经验选择下一步，保留完整会话并自动压缩长上下文。可通过原生子 Agent 并行调查，汇总后形成一致判断。内部实验和工具衔接无需用户另行编排。

↓ 分成可独立完成的工作

调查需求

优先使用 Codex 实时搜索，按需要组合公开来源、可选的 Tavily、TikHub 和通用浏览器。账号页只使用本任务已授权的账号；某个供应商或来源受阻时，其他可用来源继续。

制作内容

Codex 使用有依据的承诺和素材生成内容，按需要调用现成 Skills、插件和媒体工具。可选视频失败时，合适的文字工作仍可继续。

核对账号

按当前任务要求寻找发布或回复方法，平台独立核验当前身份、可运营位置与能力。原浏览器和账号资料继续使用，接入缺口会单独说明。

推进渠道操作

Codex 结合获准页面的结构和当前截图推进工作，工具逐项重验身份和权限。提交前核对实际身份、位置、正文和原帖；新站点先核对规则与编辑器；规则在其他页面时，查阅后回到实际编辑器继续。操作仍沿原 Action 记录。

观察实际结果

独立核对发布回执、到站与可信业务事件，识别需求、分发或产品价值的断点。执行结束与真实业务成功分别记录。

恢复受影响工作

追加要求进入原会话。设备断线或进程重启后，先核对原线程、任务和外部动作，再继续原工作；无法确认的执行保持未知，不通过换新会话或重发推进。

↓ 保存真实产物、回执与业务证据

事实支持下一次判断

复用仍适用的来源、结论和操作经验，新证据可以修正旧经验；没有经验也可继续。累计同一问题的投入。没有新学习或真实进展时，停止重复工作，选择有依据的替代路径。

等待只影响相关工作

  • 一个账号登录失效、审核未结束或网页不可读，不会暂停其他独立账号和任务。执行设备离线的工作等待同一设备恢复。
  • 兼容账号共用持久浏览器，在各自固定页面并发；同站多账号、出口或登录冲突时分开。同账号一次执行一项写入，原操作的只读核对可与另一项独立写入并行。等待本人输入会释放执行槽。
  • 账号暂停、项目暂停和解除绑定作用于同一份控制状态。中断先阻止后续提交，已经发生的操作和晚到回执仍保留。恢复后重验身份，旧权限和旧命令不能复活。

结果有明确依据

  • 草稿、已提交与已确认发布分别记录。提交结果未知时，只核对原操作，避免重复发送。
  • 点击、访问和注册各自代表对应环节。核心价值新增需要可信业务证据；缺少口径或历史时显示未知。
  • 成果按明确的主体、口径和窗口去重。邀请来源与直接渠道来源分别记录，测试与验收事件不计入客户成果。
  • Codex 用量、供应商费用和历史未知账目分别保留，不把 token 统计当作实际扣费。经营事实及经验来源继续由 Lead 保存；私有资料和账号权限不随经验转移。
工作台只保留产品目标、实际工作、真实结果、账号控制和必要本人事项。一次成功说明路径可能成立，仍需继续验证能否稳定带来价值。
