# 浏览器运营适用范围核对

核对日期：2026-10-29。本文件记录公开材料与工程开放结论；不是平台书面许可。账号所有者授权、平台允许相应操作、真实技术验收是三个独立条件。以下均不涉及私信、拉群、自动关注、采集第三方内容、购买广告或制造互动。

| 平台 / 目标 | 已核对材料与适用范围 | 当前开放结论 |
|---|---|---|
| Telegram / 自有广播频道 | [Terms](https://telegram.org/tos?setln=en)、[Content Licensing](https://telegram.org/tos/content-licensing)。禁止垃圾信息；AI/内容采集有额外限制。适配器只核对当前账号、目标权限与本次内容回执，不向模型导出第三方消息。地区年龄要求按所在地另核对。 | 按[自有频道记录](telegram-owned-channel.md)进入明确内容的首次实号验证；该内部判断不代表 Telegram 批准 lead。未验收前不自主提交。 |
| Facebook / 有管理权限的 Page | 尝试访问[Terms](https://www.facebook.com/legal/terms)与[自动化采集条款](https://www.facebook.com/legal/automated_data_collection_terms)，官方页面在本轮返回登录/访问限制。不能凭第三方转载替代完整材料，也不能把 Page 管理权解释为浏览器自动化许可。 | 不开放自主发布；需要适用地区官方条款及具体操作范围核对，再做 Page 身份/格式验证。 |
| Instagram / 自有主页 | [官方 Terms 入口](https://help.instagram.com/581066165581870)本轮返回 429/访问限制；本次未取得完整原文。 | 不开放自主发布；需要官方材料与适用授权，不把已登录视为获准自动化。 |
| YouTube / 自有频道 | [Terms，Permissions and Restrictions](https://www.youtube.com/static?template=terms)规定自动化访问通常需要事先书面许可，搜索引擎例外不适用于本产品。自有内容商业推广允许不等于自动化访问获准。 | 缺少适用书面许可时不开放浏览器自主发布。适配与本地上传测试保留。 |
| TikTok / 自有主页 | [Other regions Terms](https://www.tiktok.com/legal/page/row/terms-of-service/en)明确限制自动脚本与服务交互；该文本不覆盖美国、EEA、英国、瑞士、印度，商业条款还需另核对。 | 不开放自主发布；先确定账号地区及特定授权，不能把全球市场视为同一适用文本。 |
| X / 自有主页 | [Automation Rules](https://help.x.com/en/rules-and-policies/x-automation)明确不允许脚本操作网站等非 API 自动化。 | 当前要求采用浏览器，因此受限，不开放。保留本地适配合约，不绕过开关。 |
| LinkedIn / 自有主页、管理 Page | [Prohibited software and extensions](https://www.linkedin.com/help/linkedin/answer/a1341387/)明确限制第三方软件自动操作网站，包含发帖等动作。 | 两类目标均受限，不开放浏览器自主发布。 |
| Reddit / 管理 subreddit | [User Agreement](https://redditinc.com/policies/user-agreement)对自动访问、数据获取和服务干扰设限；管理员身份并不提供第三方商业自动化的独立许可。 | 不开放自主发布；先核对商业使用、访问方式及 subreddit 规则/管理权限。 |
| Pinterest / 自有 board | [Terms](https://policy.pinterest.com/en/terms-of-service)限制未经预先许可的自动化访问内容。页面另预告 2026-11-12 新条款；当前不能把未来文本算作已生效。商业账号/推广还适用商业材料。 | 缺少相应许可不开放自主发布；新条款生效后需重新核对。 |
| Threads / 自有主页 | [官方 Supplemental Terms 入口](https://help.instagram.com/769983657850450)本轮跳转登录；未取得当前完整原文，也未确认与 Instagram 条款的具体适用关系。 | 不开放自主发布；需取得官方文本及适用结论，不直接套用其他产品的许可。 |
| WhatsApp / 管理 Channel | [Terms](https://www.whatsapp.com/legal/terms-of-service)限制未获授权的非个人使用及不允许的自动通信；欧洲、英国适用另列文本。Channel 单向更新与普通消息不同，不能把 Business Platform 许可直接移用到 Web Channel。 | 不开放自主发布；核对账号地区、Channel 条款与该操作的明确授权后再做实号校准。 |

结论直接影响上线范围。不能以指纹、代理或操作像人来替代上述条件，也没有“登录就默认全部可运营”的实现。当前数据库对 Telegram 以外的平台保持 pending/restricted，没有因本地网页测试变为 approved。未取得官方原文的条目明确保留外部条件；未完成的是具体材料和授权，不再笼统标为开发中。

已具备的首期格式及逐平台技术验收任务见 [CHANNELS](../CHANNELS.md) 和 [DEVELOPMENT_PLAN](../DEVELOPMENT_PLAN.md)。本轮没有向任何真实社媒账号提交内容。
