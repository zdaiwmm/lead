# Telegram 自有频道发布范围

审查日期：2026-10-29。范围仅限用户已登录且有发布权限的自有广播频道。

- 用户启动/恢复已登录账号即委托 Agent 筹备和运营。服务端保存与稳定账号 ID 绑定的委托，再按实际核验结果生成具体频道授权，默认每天最多 3 条。
- 未绑定频道时允许创建业务专用广播频道和设置公开链接；跳过邀请联系人。名称、描述和专属链接先持久化；创建确认丢失时只核对，不重复创建。
- 本自有频道模式不私信、不加入第三方群组、不采集群成员或聊天历史。用户另行显式启用的社群策略采用独立账号委托和任务，见 [社群培育策略](community-growth.md)。
- 账号识别和频道权限由确定性适配器在浏览器内读取；只将稳定账号/目标标识返回受控服务。
- 回执核对在浏览器内匹配本次已授权内容的唯一标识，只导出匹配的消息 ID；不把其他消息送往模型。
- 首次验证沿用完整内容卡、任务、动作账本和回执校验。账号委托有效时由确定性服务在委托范围内安排验证，无需用户再次确认卡片；未委托时保留显式卡片流程。取得实际回执前技术能力保持 unverified。
- 任何账号、权限、频道或结果不确定时停止新提交，不自行更换目标或再次点击。

Telegram 禁止垃圾信息，并对内容采集和 AI 使用规定了额外范围。用户只授权自己的账号和目标，不意味着可以采集其他人的内容。
