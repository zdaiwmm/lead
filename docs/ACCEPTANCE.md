## 本轮补齐的工程内容

- 十个平台独立网页适配与 Telegram 媒体流程；真实文件选择、上传字节验证、图片/视频组合、标题和必要披露。
- 素材解码、图片隐私元数据清洗、视频安全容器重封装、容量/并发限制、跨 Agent 引用和内容篡改拦截。
- 统一持久准备与发布账本；上传后中断不重传，提交确认丢失不重复点击；作者和目标信息不能由正文中的链接冒充。
- 首次验证只能由完整内容一致的已接受授权卡、实际发布 ID/证据和已确认的尝试记录提升；按目标、格式、适配版本记录。
- 偏好与素材声明形成新配置版本，使旧方向排队内容失效；不会要求用户每日分配工作。
- 网页资料全文检索、所有者鉴权 SSE、独立服务端转化回传和持续集成。
