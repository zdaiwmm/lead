# Design

## Scene

小团队负责人白天在明亮办公室中短暂打开产品，想迅速确认运营是否正常以及最近带来的访问。采用明亮、安静的产品界面。

## Direction

Restrained。暖灰画布、接近白色的内容区、深灰正文、少量草绿色状态。参考 Notion 的留白、Linear 的列表秩序与 Stripe 的清晰数据排版。用户已确认简约界面、最少配置与深层高级设置。

## Typography

系统无衬线中文字体，固定字号，数字使用等宽数字。正文 14px，主标题 28px，次标题 18px。使用权重、留白和对齐建立层次。

## Components

宽松列表和分隔线为主，少量必要卡片。按钮统一 8px 圆角，主按钮深灰实底，状态使用文字与小圆点。表单使用可见标签。图表为克制的绿色折线图，数据缺失显示未知，不能以演示值代替。

## Task Brief

真实服务驱动的产品，桌面优先并适配手机。总览、Agent 列表、Agent 详情、业务输入、账号连接、启动、暂停、恢复、接管与深层偏好均可使用。浏览器操作和统计均使用实际记录。创建采用独立流程页面，不用大表单弹窗。影像探索跳过：本轮验收关注已确认的精简操作路径与信息层次，没有待选择的视觉方向或需要生成的位图资产。
