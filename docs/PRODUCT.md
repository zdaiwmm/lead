# Product

## Register

product

## Users

运营小白、小团队创始人和产品负责人。用户希望告诉平台要推广什么、登录社媒账号，即可雇用持续自主工作的 AI 运营人员，并通过真实获客效果决定是否继续使用。用户不熟悉模型、提示词、浏览器环境或任务编排。产品和范围已经在本聊天的多轮讨论中确定，用户已明确要求按照原方案实施并在本地运行。

## Product Purpose

正式本地产品覆盖输入业务网址或介绍、连接账号、免费启动 Agent、多个 Agent 并行运营、查看有效访问和近期工作、暂停与接管。界面接入持久业务服务、真实浏览器和模型；实际效果来自有来源的数据回传，不使用演示成果。

## Brand Personality

简约、清楚、可靠。用户确认 Huly 的局部氛围、Raycast 的色彩表现与 Linear 的界面秩序，沉淀为石墨暗色、珊瑚操作、紫罗兰数据与薄荷状态。明确模块边界和宽松间距，保持轻量干预。产品名为 lead。

## Anti-references

避免技术控制台、模型参数面板、日志主屏、大量说明文案、多层卡片和需要每天手动启动的工作流。

## Design Principles

1. 首屏优先回答运营状态、近期工作和获客效果。
2. 创建仅收集必要业务信息和账号连接。
3. 多 Agent 并行状态清晰，用户不负责日常任务编排。
4. 业务偏好、运营偏好、工作记录与高级用量摘要直接展示，按语义独立成区；编辑、更多与完整内容使用独立弹窗，保持主页面布局稳定。
5. 演示状态、空状态和真实连接边界清楚，避免模拟成果冒充真实成果。
6. Agent 页面以自主运营和获客结果为核心。桌面右侧对话为辅助模块，用于补充信息与调整方向；偏好、账号、必要确认和用量在主区可直接处理。新建先通过分步弹窗介绍业务与运营方向，验证首个渠道后进入主页面；Agent 后续继续逐步完善。
7. 所有社媒图标同时展示，连接与运营状态分开；每个平台支持独立启动暂停，低频控制放在平台管理弹窗。
8. 未接入的数据保持未知，不用示例数字、趋势或增长率替代真实记录。

## Accessibility & Inclusion

采用清晰对比度、可见键盘焦点、语义化控件、明确字段标签、移动端适配和减少动态效果支持。此为实现基线，不声称已经通过正式认证。
