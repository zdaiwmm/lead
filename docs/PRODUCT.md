# Product

## Register

product

## Users

运营小白、小团队创始人和产品负责人。用户希望告诉平台要推广什么、登录社媒账号，即可雇用持续自主工作的 AI 运营人员，并通过真实获客效果决定是否继续使用。用户不熟悉模型、提示词、浏览器环境或任务编排。产品和范围已经在本聊天的多轮讨论中确定，用户已明确要求按照原方案实施并在本地运行。

## Product Purpose

正式本地产品覆盖输入业务网址或介绍、连接账号、免费启动 Agent、多个 Agent 并行运营、查看有效访问和近期工作、暂停与接管。界面接入持久业务服务、真实浏览器和模型；实际效果来自有来源的数据回传，不使用演示成果。

## Brand Personality

简约、清楚、可靠。用户确认 Huly 的局部氛围、Raycast 的色彩表现与 Linear 的界面秩序，沉淀为石墨暗色、珊瑚操作、紫罗兰数据与薄荷状态。明确模块边界和宽松间距，保持轻量干预。产品名为 lead。

## Anti-references

避免技术控制台、模型参数面板、日志主屏、大量说明文案、多层卡片和需要每天手动启动的工作流。

## Agent 持续运行契约

持续运营属于产品 Agent 的职责。运行中的 Agent 由项目自身的持久工作流排期、恢复和选择下一项有条件的工作，不依赖用户每天发消息，也不依赖 Codex 定时监督。Codex 负责修复和验证项目缺陷；Codex 自动任务不承担产品日常运营，不作为默认运行依赖。

- 内容筹备、公开研究、账号筹备、已授权发布和结果复盘分别判断来源、能力、权限与下一次执行时间。单一渠道等待不应让其他满足条件的工作一起停下。
- 临时故障保留原任务和证据，按退避继续；结果未知时核对同一外部动作，不能通过新建频道、重建任务或盲目重发制造进度。只有完整证明原稿未生效的限定恢复路径才能继续原提交，恢复次数必须持久化并有上限。
- 无账号时可以完成有来源的选题、草稿和素材准备；没有真实指标时可以继续有界探索，不能虚构效果。素材制作仍须逐步补齐自动选题、受众语言和质量检查，不能把人工准备样稿等同于这些行为全部已自动化。
- 暂停、归档、撤销授权、工作时段和预算限制继续生效。确实没有任何可执行工作时，保存具体等待原因与到期时间；必要输入集中提出，不把日常内容安排交回用户。
- 完成步骤、失败恢复与下一步均需保留可查询记录。运行重启后由产品的持久状态继续，正常工作保持安静；只有必要授权、异常或有意义的成果需要用户关注。

当前实现已具备持久 Supervisor 计时、无账号底稿、公开研究与频道任务的独立推进、暂停与原任务核对。素材样稿的自动语义质量、全部渠道实号验收和真实获客闭环仍按交付计划推进，不能据此宣称全量自主运营已完成。

### 全天候运营循环

运行目标为全天候自主经营，工作日、时区与预算等显式限制优先。Supervisor 在完成一步后自行选择下一项到期且有条件的工作：

1. 核对业务目标、来源版本、预算、暂停与账号权限。
2. 维护渠道底稿；渠道尚未就绪时，主动补充有来源的具体内容储备，支持文字及适用的图文/讲解视频，不等待发布权限才开始准备。
3. 独立推进已启用的公开需求研究；账号筹备和未知发布分别核对原任务。
4. 在目标和格式验证通过后，按原发布节奏使用准备好的内容，保留内容来源及任务关联。
5. 根据真实回执更新已完成状态；有真实效果数据时复盘，没有回传时保留未知。
6. 保存下一项任务与到期时间，由产品持久计时再次执行。一个方向等待时继续其他满足条件的工作。

当前内容储备每个待就绪渠道最多三篇，一轮最多准备一篇，每日最多新建十二项；失败间隔十分钟，每项最多尝试三次，并继续受工作室模型额度控制。储备充足、全部任务尚未到期或存在必要权限等待时，应明确展示等待原因与下次检查时间，不重复生成相同内容。该机制不提高原有发布频率，不要求全天候对外发送消息。

工作流状态进入 Agent 的对话上下文，并可从运营准备接口查询；必须区分“后台在线”和“正在产生业务成果”。本机版本需要电脑和服务持续运行，休眠/关机期间不能执行；真正全天候在线需常驻节点或持续开机的主机。连续二十四小时可靠性仍需足够时长的实测，短时计时回归不替代该验收。

## Design Principles

1. 首屏优先回答运营状态、近期工作和获客效果。
2. 创建仅收集必要业务信息和账号连接。
3. 多 Agent 并行状态清晰，用户不负责日常任务编排。
4. 业务偏好、运营偏好、工作记录与高级用量摘要直接展示，按语义独立成区；编辑、更多与完整内容使用独立弹窗，保持主页面布局稳定。
5. 演示状态、空状态和真实连接边界清楚，避免模拟成果冒充真实成果。
6. Agent 页面以自主运营和获客结果为核心。桌面右侧对话为辅助模块，用于补充信息与调整方向；偏好、账号、必要确认和用量在主区可直接处理。新建先通过分步弹窗介绍业务与运营方向，验证首个渠道后进入主页面；Agent 后续继续逐步完善。
7. 所有社媒图标同时展示，连接与运营状态分开；每个平台支持独立启动暂停，低频控制放在平台管理弹窗。
   账号管理提供二次确认的“解除绑定”；已连接、登录失效和受限账号均可释放占用，让其他 Agent 在自己的浏览器中重新登录绑定。解绑撤销原运营授权与未提交任务，保留历史和待核对结果，不转移浏览器登录状态；过期确认不能解除刚更新的连接。
8. 未接入的数据保持未知，不用示例数字、趋势或增长率替代真实记录。

## Accessibility & Inclusion

采用清晰对比度、可见键盘焦点、语义化控件、明确字段标签、移动端适配和减少动态效果支持。此为实现基线，不声称已经通过正式认证。
