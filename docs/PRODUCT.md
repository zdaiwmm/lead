# Product

## Register

product

## Users

运营小白、小团队创始人和产品负责人。用户希望告诉平台要推广什么、登录社媒账号，即可雇用持续自主工作的 AI 运营人员，并通过真实获客效果决定是否继续使用。用户不熟悉模型、提示词、浏览器环境或任务编排。产品和范围已经在本聊天的多轮讨论中确定，用户明确要求按照已确认方案制作原型。

## Product Purpose

交互原型覆盖输入业务网址或介绍、连接账号、免费启动 Agent、多个 Agent 并行运营、查看有效访问和近期工作、暂停与接管。原型使用明确标记的演示数据和模拟连接，不执行真实社媒操作。

## Brand Personality

简约、清楚、可靠。用户明确要求少提示文案、少表单、高级配置入口放深。产品名为 lead。

## Anti-references

避免技术控制台、模型参数面板、日志主屏、大量说明文案、多层卡片和需要每天手动启动的工作流。

## Design Principles

1. 首屏优先回答运营状态、近期工作和获客效果。
2. 创建仅收集必要业务信息和账号连接。
3. 多 Agent 并行状态清晰，用户不负责日常任务编排。
4. 高级偏好与运行记录放入详情的次级入口。
5. 演示状态、空状态和真实连接边界清楚，避免模拟成果冒充真实成果。
6. 正式产品在对话中创建和管理 Agent，由 Agent 逐步补问必要信息；对话同时支持运营查询、想法讨论和偏好调整，后台默认自主工作。

## Accessibility & Inclusion

采用清晰对比度、可见键盘焦点、语义化控件、明确字段标签、移动端适配和减少动态效果支持。此为实现基线，不声称已经通过正式认证。
