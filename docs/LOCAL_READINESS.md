# 本地试用交付

日期：2026-10-29。正式公网部署不在本轮执行。

打开 [lead](http://127.0.0.1:3100/)，点击“雇用 Agent”，在对话中介绍业务或输入产品网址。可以讨论运营想法、保存和纠正偏好、上传素材、查看网页来源、连接专属浏览器、暂停与接管。用量和数据导出在“更多 → 高级设置 → 用量与数据”。模型密钥继续从本地 `.env` 读取，不需要重新填写。

本轮补齐了固定出口池与原子分配、出口停用后的自动等待、设备/地区一致性和系统边界实测状态、恢复隔离到新节点的切换工具、安装与升级检查、所有者绑定、素材原话来源、详细用量、导出与明确归属的保留/清除工具。活动网页研究与自动备份现在互斥，创建完成后也不会再清空刚输入的草稿。维护唤醒会遵守已保存的运营排期；真正缺少必要事实时会在对话中问一次，等待补充，不靠重复发帖或无声停工。

本地网页测试涵盖 11 个平台的 21 种媒体组合。扩展的混合预演已有三浏览器原生上传区间重叠、接管时其他 Agent 继续、确认丢失后重开核对、真实数据库连接中断和持久任务重试的证据。短跑只证明这些受控路径，72 小时的自动判定还要求足够时长、预热后资源样本和不变的执行代码。

真实运营需要在专属浏览器完成本人账号登录、目标授权和首次格式验证。11 个平台的线上验收均未完成；部分平台的公开条件限制浏览器自动化，详见[逐平台记录](policies/CHANNEL_REVIEW.md)。不会用本地测试结果、平台图标或已登录状态冒充可自主发布。获客数字来自真实网站接入，未接入显示未知。

当前仍需外部条件：正式 Linux 节点及 HTTPS、真实身份服务与异地存储、三个固定独立出口、各平台适用权限及实号验证、业务网站接入。成本记录已能保存实际单位；未登记版本化价格或未实测的基础设施成本保持未知。无需把这些配置放进普通用户创建流程。

维护方法与具体操作见 [OPERATIONS](OPERATIONS.md)；后续状态见 [DEVELOPMENT_PLAN](DEVELOPMENT_PLAN.md)。原有业务和登录资料保留。
