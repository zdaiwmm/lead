# 本地验收记录 · 2026-10-29

## 自动验证的范围

完整自动测试使用真实 PostgreSQL 和原生 Camoufox，覆盖：

- RLS、复合外键、不可变配置/内容、创建和消息去重、授权版本、控制屏障、预算与网址边界。
- 十一个平台的 21 种原生图片/视频网页合约；真实文件选择与上传字节/哈希、表单输入、提交次数、回执及只读核对。
- 上传后准备中断、提交后确认丢失、账号切换、页面变化、正文改动、正文引用他人主页不能冒充作者，以及验证格式不会由普通测试自动提升。
- 图片实际解码、EXIF 清除、视频实际解码/重封装、非法容器/协议、文件篡改、范围隔离、大小限制和磁盘空间预留。
- 偏好添加/替换/删除的版本与幂等；假设性对话不能改偏好；撤销偏好后旧排队内容取消；素材声明必须来自明确用户陈述。
- 已保存网页中英文检索、最新来源版本、软删除与跨 Agent 隔离。
- 转化密钥与公开网站代码凭据区分、轮换、已有归因会话验证、重复事件不重复计数、篡改事件拒绝、断开覆盖显示未知。

本地页面合约不能证明真实社媒线上行为。不得把这些测试提升为平台实号验收。

## 公网与真实模型链路

- `.state/public-browser-verification.json`：产品 API → Temporal → 已配置 DeepSeek → 原生浏览器工具 → 公网 Seka，实际点击和来源/截图。
- `.state/runtime-verification.json`：三 Agent 并行模型对话、偏好保存与隔离、自主规划到真实浏览器本地发布、测试成果不计获客。
- `.state/concurrency-verification.json`：三环境公网浏览时间区间实际重叠，单环境暂停不影响其他环境。
- `.state/environment-verification.json`：真实浏览器两探针出口测量；没有固定独立代理的环境仍保持未验证。
- `.state/test-results.xml`：最新完整自动测试结果；执行命令与前端构建方法见 README。

运行报告、截图、账号资料及业务数据仅保存在本机 `.state/`，不上传公开仓库。
