# 隔离 Worker 模型凭据与连接恢复

## 范围与验收

用户于 2026-11-11 授权修复聊天 Worker 的凭据挂载、重启并验收原消息；后续明确授权在 OpenAI 返回额度错误后切换对话到已配置的 DeepSeek 重试。另一个发布聊天已取得同步并协调发布的授权。

API 可以读取模型凭据，Worker 缺少同一只读文件绑定；补齐后又因隔离网络中缺少模型通道适配而连接失败。节点已有专用模型 Unix socket。本次提供由部署方配置、精确到 Agent 和供应商的通道，无私有 Agent ID、凭据或生产数据进入公开仓库。未配置通道时保持现有连接方式；配置错误或通道断开必须报错，不回落其他出口。HTTPS 证书与主机验证保留。

验收：两家官方端点可按各自通道连接；不同 Agent 不共用配置；非法路径、错误供应商、HTTP、非官方域名、URL 用户信息和重定向不能发送凭据；模型调用的两条分支都使用显式通道。连接成功、模型可用和生成成功分别验证，429 不能算处理完成。
