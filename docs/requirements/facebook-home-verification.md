# Facebook 首页完成登录核验

## 范围与验收

用户在 2026-11-11 反馈两个相继出现的问题：登录成功后点击「验证并完成」被「正在完成输入」拦住；随后中文 Facebook 首页显示已登录，却提示「请先登录 Facebook 并打开自己的主页」。用户明确要求无需进入个人主页，授权更新线上，并允许与浏览器修复聊天协调统一发布。

输入请求与截图刷新分离，验证等待已排队输入完成后继续。等待期间阻止新输入和重复提交；输入失败、45 秒无回执、接管过期均恢复明确状态，不自动重放可能已执行的输入。中文首页核验使用当前会话的唯一有效 c_user 身份与可见账号入口；支持简体、繁体及原英文界面。保留登录页、验证关卡、密码框、缺少身份或界面证据时的拒绝，不扩大自动运营授权。

可观察验收：无需打开个人主页；慢截图不阻塞验证；输入顺序保持；失败后不结束接管或假报成功；重试不重复输入；保留 main 的精确 account_id、takeover 和 managed-target 回调语义。
