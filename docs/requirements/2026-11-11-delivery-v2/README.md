## 端到端接入

- PR 不再跑应用全量；合并后 main 按显式路径/文件模式选择 docs、tools 或 application，未知/混合/手动/缺历史回退应用。应用保留原全量与同轮 SquashFS；维护工具保留专用回归和真实 Linux 演练，不启动数据库/浏览器业务全量。
- 新放行证明按用途区分。request_home_release、prepare_home_image、poll_home_release 的默认应用验证契约兼容旧应用 CI；新流水线必须有完整应用证明。工具/文档/PR/跳过/失败/旧 attempt 不能放行应用。独立工具入口要求工具或完整应用证明及工具包成功。
- main 验证通过后从精确 Git 源码构建确定性工具包，绑定 SHA、run/attempt、GitHub 产物摘要与每个源文件摘要。工具源码不进入业务镜像，不再为每次工具源码变化手改服务器摘要白名单；未知 scripts、运行依赖与主机配置继续原核验。

- 原发布工作流及平台环境审核保持；授权改为需求/环境级，精确 SHA 由 Agent 固定记录，不增加重复聊天确认。
