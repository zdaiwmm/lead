- 本次已获授权的工作包括整链盘点、沿现有能力的必要接通及相应交付/真实核验。用户明确授权自主找群、加入、发布、回复等非付费获客行为，不接受维护者建议的“两条文字/24小时、不加群、不私信、不发媒体”作为本次用户限制；实际执行仍核对账号委托、平台规则、目标许可、费用和未知结果围栏。不恢复旧 revoked grant，不解除两个旧频道的排除，不扩大凭据或隔离权限。需要登录时用户可在原专属浏览器完成。

### 完成条件

1. 选定且记录一条当前可执行的真实业务路径，包含账号主体、目标、实际受众、内容范围、工具路由、观测信号和下一轮条件。开工前集中列出用户需补的输入，不要求重新设计每个模块。
2. 产品内经营Agent使用已有原生任务和工具取得所需真实证据，明确区分原文、渲染后的界面、owner_asserted事实及尚未体验的功能；不以搜索摘要、加载页或编造步骤替代。
3. 模型在当前授权范围内选择并完成有业务用途的外部动作。实际账号/目标/内容、原Action及唯一提交归属一致；未知只回读原动作，不换会话、换幂等键或重复提交。
4. 独立回读该次外部动作的真实可见结果，并由原结果接入读取适用观测窗口的可信信号。没有接入的指标为unknown；没有转化不等于执行未完成，也不能记为获客成功。
5. 原调度器基于该结果自然推进下一次模型决策和适当的有界工作并完成，不依赖维护者再次下经营指令。测试通过、进程在线、接受提案、研究或草稿完成均不单独计为本次完成。
6. 原历史、费用、未知结果、问题预算及账号/项目围栏保留。验收或团队访问不计为真实获客；不清库、DDL、重置预算或放宽网络/文件/凭据隔离。
