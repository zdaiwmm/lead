## 已实施与已验证

渠道时钟按启用的目录项和控制版本持久登记。每种渠道在独立 Temporal 工作流中按目标期限轮转，等待不占执行槽。已有增长实验继续由实验内核负责，其他已迁移的发布只由渠道时钟选择。最终产物提交与网页点击前再次核对时钟代数。复用已有选题、平台许可、目标资格、素材校验、发布任务、唯一分发码及首次归因；时钟可把与目标、产品版本匹配的已核验机会传给内容决策，研究证据本身不授予发帖权限。

已在单独创建的 PostgreSQL 数据库、原生 Camoufox 和离线 Facebook/Reddit 页面复现从模拟机会报告到客户首购的路径：读取经核验的样例需求、确定目标、生成内容、保存发布计划、点击、回读和首访归因。平台和模型使用固定替身，账号、站点及交易为测试样本。Facebook 已接收帖子后故意丢失返回，原动作进入未知，再次执行只回查，两个平台各留下一个帖子。模拟访客先走 Reddit 链接再走 Facebook 链接，在后者完成购买，重复回调后项目一人且归 Reddit。独立测试与历史回归合计 54 项通过。
