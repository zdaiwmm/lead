# 多渠道原子底稿与首次渠道获客试点

## 范围与验收
用户已确认在 Lead 复用主线并发工作，先以 Reddit、Facebook 打通独立任务、遇阻让出、首次到站归因与动态启停。选用不需要向外部账号发送内容的真实底稿产物。两个渠道可同时生成；阻塞的工作记录原因，在等待期释放执行位；其他渠道可生成、启用和暂停。成交回访沿用原交易证据，新增客户只归首次到站；重复事件、首次直访及缺证据单独核对。

## 实施与交接
基线 fe3716c，分支 codex/channel-atom-first-entry，独立工作区；原工作目录保留未提交工作。此任务针对本地隔离验证，不涉及部署。

## 运行入口与范围

1. 先在目标测试环境执行项目常规数据库升级，再把试点项目 UUID 加入环境变量 `LEAD_CHANNEL_ATOM_AGENT_IDS`（逗号分隔，默认空），API 和 Worker 使用同一配置并重启。基础账号连接及外部动作授权维持原有规则。默认主线的底稿、只读并发与原有交易归因继续保留。
2. 通过已有渠道启停入口选择已连接账号。启用渠道从运行时账号集合取得，不固定为试点的三种平台。已启用且在既有底稿目录注册的渠道创建独立持久任务，底稿计算不持项目行锁；最终持共享项目锁再核对账号、业务版本、控制版本和任务代数。正常启动、渠道变更、重新登录和 Supervisor 均能唤醒该路径。
3. 底稿的两路执行复用 lead-offline 工作队列，不涉及浏览器写操作。缺登录时保存等待原因；最终校验前已完成的底稿可保存检查点，重新登录自动恢复。暂停频道阻止旧代数交付。数据库锁超时回滚并让出槽，交给 Temporal 有界退避（最多 8 轮）；耗尽后停止本次任务。无权限时不会进入发布流程。
4. 可通过现有建链接口生成 rd_ 和 fb_ 来源短码。正常落地依次经过签名跳转、站点 PageView 和服务端首次业务回传。订单快照继续用于交易核验；新增客户从项目所选站点、正式环境和具有可信稳定身份的合格事件中按客户取首次，再按最早实际 PageView 的已验证渠道分组。先按全历史取首次再过滤报告期，复购不会在下个窗口变成新客。新客定义沿用现有业务首次事件契约与“当前获客策略”设置。报告读取现有运营计划接口，显示渠道、来源未知与已观测合计。
5. 首次到站无签名来源，后来的短链无法覆盖；共享匿名设备被多个服务端客户身份认领时保留来源未知。站点连接各自持有身份命名空间，暂不跨站合人。升级以前缺乏直接证据的历史回执不被扩充成可信新客。开关关闭后恢复原显示和调度，升级后的原始交易快照、分发码及历史产物保留。

## 本次隔离验收

使用临时 PostgreSQL 18 和独立 Temporal 开发服务，走真实数据库迁移、事务 outbox、Temporal 工作流和活动、渠道控制、短链／像素／服务端事件与运营计划接口。账号和客户为测试样本；Reddit 底稿故意延迟，外部社交网站没有参与试验。

| 验收项 | 结果 |
| --- | --- |
| 并行及动态增减 | Reddit 活动尚未释放时 Facebook 完成并入账。暂停／恢复运行中任务，旧代数不能覆盖新任务；动态加入 Instagram 可以完成。各渠道最终各有一份底稿 |
| 撤出及恢复 | 制造 Reddit 登录失效，核实 waiting_user 和恢复代数；重新核对登录身份，禁止再次生成底稿仍可完成。持有真实数据库行锁时在 Temporal 历史看到 TIMER_STARTED；释放后完成，历史重放通过 |
| 首次进入归因 | A 先从 Reddit 到站后从 Facebook 首购；B 从 Facebook 进入并首购；D 直接进入后从 Facebook 首购。结果为 Reddit 1、Facebook 1、来源未知 1、已观测 3。回调重放和 A 跨期再次购买均不增加人数；共享设备双客户另测为未知 |
| 回归范围 | 隔离回归 93 项通过；10 项另需原生 Camoufox 或专用传输故障配置的用例跳过。新增真实 Temporal 用例在本次启用了独立服务并通过。Python 静态检查、前端 TypeScript 类型检查、差异空白检查通过 |

复验时指定独立的 LEAD_STATE_DIR、LEAD_DB_HOST、LEAD_DB_PORT，并用 LEAD_TEST_CHANNEL_TEMPORAL 指向**仅供本次测试**的 Temporal 服务（该用例消费 lead-offline 队列）。执行 tests/test_channel_atom_pilot.py、tests/test_pixel_events.py 及既有 tests/test_dispatch_plan.py、tests/test_atomic_read_batch.py 等回归。未测真实平台发帖、平台获客数量、多站点身份归并或生产容量。
