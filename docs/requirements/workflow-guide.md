# 工作台自主运营流程图

## 范围与验收

用户要求在通知上方增加流程图入口，弹窗内随时复习。保留九步节点、条件去向及排障说明，以同一时刻的新线索、待发稿和昨日未知提交说明并行与等待。用分级排版区分判断、行动和记录。流程变化须同步维护。

入口对尚未选择 Agent 的用户同样可用。验收桌面和手机入口、打开关闭及返回、条件跳转、两种账号分配下的依赖和只读回查。说明使用假设案例，不读取实际运营记录。

## 实施与交接

任务分支 codex/workflow-guide，基线 f1385b6。范围为工作台帮助内容、入口与维护约定。

弹窗复用工作台既有对话框。页面内容集中维护在 apps/web/public/workflow-guide.html；仓库入口规则与 PR 模板已加入流程变更的对照检查。

前端生产构建与类型检查通过。独立本地前端使用模拟账号接口，在 Chrome 以 1280、390、320 像素宽度从侧栏打开，核对入口顺序、账号 A／B 切换、回执节点跳转、排障展开、图内 Esc、关闭按钮和焦点返回。三个宽度的页面均无整体横向溢出。属于本地界面验收，线上设备与真实账号未参与。
