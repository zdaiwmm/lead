# 家庭普通浏览器运行环境

## 范围与验收

主线 f1385b6 已将 Chamber 的 Reddit 人工登录分配到独立资料目录。2026-11-10 公网实际重试时，Camoufox 在启动前尝试创建 /tmp/.camoufox，服务挂载只读。项目已分配固定 IPv6，普通服务所在的网络空间没有该地址。用户确认继续修复并隔离验证本次节点问题。

普通执行器使用自己的可写运行目录。仅为指定项目接入原已核准的 IPv6 出口，单独挂载浏览器出口套接字。DNS、网页连接和两项出口探针均须经该出口。保留浏览器进程隔离、资料独占、原项目的登录与权限边界。测试使用新账号资料，不登录任何真实账号。

## 家庭节点隔离实测

临时服务使用 PrivateNetwork、PrivateDevices、ProtectSystem=strict 和 NoNewPrivileges，挂载相同的只读 SDK、引擎、指纹模型及单一浏览器出口套接字。未挂载业务数据库、生产账号资料、模型套接字或私人凭据。新建的浏览器安全边界回执为 verified，直接 UDP 被拒绝，浏览器只看见回环接口。ipify 与 Cloudflare 同时测得与项目分配完全相同的 IPv6。启动成功使用普通系统 bwrap 和只读 SDK 缓存，未增加服务能力。

实际导航 www.reddit.com 在本次线路上返回 NS_ERROR_PROXY_BAD_GATEWAY。经同一出口查询该域名与 oauth.reddit.com，AAAA 查询仅给出 CNAME，A 查询给出四个 IPv4。无 www 的域名有 AAAA，本轮尝试其公开 IPv6 时上游 SOCKS 未建立连接。生产资源池中 IPv6 已分配，唯一 IPv4 已禁用且已有分配。当前范围未提供给 Reddit 的 IPv4 或双栈出口，公网首帧和登录仍待验。该版本仅作为可评审的运行环境修复。

## 配置交接

`infra/systemd/home-browser-login.conf.in` 是普通浏览器单元的节点配置模板。生产变更须先核对真实项目、该项目已分配的固定 IPv6、源路径为已核准的套接字及同一套接字的可用性，再以真实值替换三个占位符。项目键为去横线的大写 UUID，目标文件名与受限的 /run/lead-egress 路径匹配。只挂载浏览器套接字。运行目录位于服务专属 RuntimeDirectory，浏览器账号持久资料仍属于原 profile。套接字重新创建后需重新绑定，并重新核对独立浏览器出口。先有适用于目标网站的可用出口，再安排生产切换和真实 Reddit 首帧验收。
