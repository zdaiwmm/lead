# 家庭节点指纹浏览器画面传输

## 范围与验收

2026-11-09 用户确认将现网画面优化纳入 GitHub，PR 检查通过后合入 main。本次交付只读核对现网；账号绑定、浏览器资料、真实截图和接管凭据均留在原节点。

- 在干净的 Linux 环境使用锁定的 Sharp 和合成截图，验证同源接管返回 AVIF，保留点击坐标和条件响应。未登录请求应得到原站拒绝，旧客户端可接收原图。
- Nginx 仅分流取图和浏览器控制，编码器离线时原 Web 服务继续处理，已送达的点击不会因重试重复执行。
- 发布包包含编码器、systemd 单元及两段站点规则。跨设备发布使用 GitHub 已合并的提交与相同提交的主线 CI 产物。
