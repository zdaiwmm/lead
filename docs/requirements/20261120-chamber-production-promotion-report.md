# Chamber 查询生产推广统计

## 范围与验收

- 生产采集器负责公网短链和网站像素数据。本机 Chamber 查询对应站点的归因统计，并从本机读取确认发布数和原文记录。
- 保留已有的单日日报。范围报表只接受北京时间当天作为查询锚点。「今日」返回 24 个小时位置。「所有」返回历史累计与近 30 天的日趋势。生产端直接计算各范围的设备去重。
- 查询只使用生产站点的只读报表凭据。该凭据只能读取已绑定的站点。短链登记使用独立凭据。接口只传递汇总数据。
- 保持已发布短链地址。生产映射启用后，工作台标明统计来自生产。本机原有点击和单帖记录通过本机明细访问。两端设备标识分别保留。
- 使用隔离数据库验证跨渠道和跨日去重、归因筛选、错误凭据、项目隔离、窗口完整性和两端传输。本机配置按 Agent 生效。生产查询失败时显示读取错误。
