# 需求名称

## 范围与验收

- 使用场景、当前问题和预期结果：
- 本次范围、影响的服务或数据：
- 用户确认的决定和仍待确认的取舍：
- 可观察的验收条件（包括失败和重试）：
- 发布批次（需要上线时）：本批纳入、必要依赖、明确排除项；生产到候选的累计差异；冻结后只因阻断项调整。

## 实施与交接

- 任务分支、起始提交、PR：
- 已完成的工作和实际运行的检查：
- 验证依据：受影响入口/调用方、风险、用例；源码 SHA、命令、环境、结果；复用证据的适用性。
- 未验证的环境、未通过的检查及原因：
- 换设备后的下一步：

## 发布记录（需要上线时填写）

- 目标环境、获确认的完整提交、CI 链接：
- 提前盘点：线上临时覆盖、接管/未决动作、备份、现有请求与发布负责人；无需记录凭据或业务内容。
- 分段耗时：PR/main CI、取件、维护等待、切换、独立核验、文档收尾。
- GitHub 部署请求、设备返回的运行版本：
- 独立核验结果、时间与证据：
- 失败后的处理、是否已恢复及仍需核对的状态：
