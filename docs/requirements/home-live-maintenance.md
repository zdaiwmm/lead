# 家庭节点维护与原授权恢复

已确认应用版本 0381326c706bd6d4fd152c984f7d120e0e8e21ad 和 shui.click 环境。用户另行同意修复节点工具、等真实任务安全结束再切换，并保持账号授权。工具独立交付，应用工件继续绑定原发布单。保留入口、设备专用执行器、认证和数据库维护锁。

维护人员先核对实际运行版本、认证健康、发布凭证、镜像摘要和回退版本。仅在事务锁内确认无进行中的业务任务后，暂存运行意愿并暂停新调度。保留待执行任务、账号绑定、委托、控制版本。已有浏览器会话自然排空后再持久持有正式维护锁。恢复仅限本次标记、同一账号权限及控制版本，遇到所有者并发修改须人工核对。切换与回退均独立验证各进程的镜像、入口和本次工作进程回执。复跑不覆盖其他维护或复开已撤销授权。

实际家庭节点在 root 管理的 release 工具目录明确安装 home_live_maintenance.py 时，控制器使用独立空工作室 viewer 和独立读取用 TLS 证书验证；其余节点沿用原入口。hold/restore 接受完整应用 SHA，维护标记及授权摘要与调度意愿在同一个数据库事务内写入。只有检查完整、运行意愿已恢复并取得真实回执才报告发布成功。
