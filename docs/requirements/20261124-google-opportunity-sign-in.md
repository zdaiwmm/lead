# 专用 Google 账号登录新平台

## 范围与验收

工作室所有者在 Agent 高级设置中绑定专用 Google 账号，按项目开启自动登录，独立决定是否允许首次免费建号。Google 密码和验证步骤由所有者在原站页面完成。Lead 保存浏览器会话、脱敏账号提示、策略和站点结果。Google 账号资料独立于公开研究浏览器与社媒账号。

仅在活跃的分发实验中，当前公开浏览任务有可回读的同站登录入口证据时才尝试登录。自动路径核对实际 Google 登录链接、授权范围、回调站点、账号及回到原站后的当前身份。登录不授予该站点的发布、提交或付费权限。权限超出、浏览器不兼容、本人验证或结果未知时显示原因，其他来源继续研究。

当前自动路径适用于能够核对完整授权 URL 的直接链接。动态按钮和弹窗若无法取得同样的证据，则记录需要本人处理。Google 对 Lead 使用的浏览器是否放行，需要用专用账号进行端到端验证。

## 实施与交接

- 基线为 GitHub main 的 `865d72a306547855ea69f3591d225daf78cacf9a`，任务分支为 `codex/google-opportunity-sign-in`。
- 独立实现界面与分发研究接点，再用服务端策略、浏览器隔离和同源证据连接。账号或策略变更立即影响后续动作，未知的外部结果先保留，原授权不自动重放。
- 准入、回调约束、浏览器代理隔离和分发研究定向回归在本地执行。真实 Google 授权和生产运行留作环境验收。
