## v5 交互

1. 未接入获客效果区只显示嵌入代码、安装检测、事件测试三步进度及当前任务按钮。收到 PageView 后才视为检测成功。待测试阶段仅有设置网站事件和统一按钮，不在页面中展示各事件、测试状态或完成接入操作。
2. 已接入后，获客效果保留独立访客、访问会话、事件三项。像素设置菜单只有嵌入指引、安装检测、事件设置与测试三个任务入口，不逐项列出事件。
3. 事件设置与测试采用一个统一弹窗，内部依次处理事件列表、添加事件、当前事件设置与测试；每次只呈现当前一步。列表内可查找已添加事件，测试完成后回列表；至少一个业务事件测试通过才可在弹窗内完成接入。也可先只接入访问。
4. 初始事件包括注册、有效使用和支付，可从添加事件中选择更多标准事件，或添加自定义事件。PageView 属于基础采集，不重复作为业务事件添加。
5. 自定义事件填写显示名称和事件标识，再定义触发行为。事件标识校验格式及大小写不敏感的重名，禁止与标准事件名称冲突。新事件在列表和数据明细中动态出现；配置及测试状态本地保存，刷新后恢复。
6. 标准事件和自定义事件均生成对应名称的示例代码，不再回落为购买事件代码。浏览器与服务端方式、来源上下文和去重说明在开发接入中按需查看。
7. 标准事件参考表保留名称、触发时机、事件类型与查找，不包含 Meta 品牌文案、外链或仅支持三个事件的提示。可从事件列表、添加、设置及测试、数据明细查看；任一时刻只打开一个弹窗。返回保留当前表单与测试反馈。
8. 事件明细动态展示已添加事件的次数、人数、最近发生及接入状态。统计口径是直接显示的普通文本区，不使用折叠控件。
9. 事件汇总为各业务事件按规则去重后的次数之和，不含页面访问和测试记录；触发人数按每个事件分别去重，不相加为总人数。正式统计仍待服务端实现，本原型表达产品口径与交互。
10. 工具条的接入完成·示例预览明确标注示例数据，汇总为 86 + 51 + 18 = 155 次，支付 18 次对应 14 人。正式数据为空仍显示未知，测试上报不作为正式成果。
11. 嵌入、检测、事件、明细和参考任务保持分离；事件列表和单事件编辑是同一事件任务中的不同步骤，没有侧栏堆叠或并列模态。
12. Agent 分享链接与像素关联契约保持不变。归因调试仍放在独立工具页，不进入用户接入流程。

## 拟议关联契约

### 像素与链接分工

- pixel_id 固定在安装代码中，映射项目，SDK 确定采集服务器。一项目可供多个 Agent 共用像素，用户无需逐条绑定。
- Agent 每次发布时生成公开、不包含用户身份的 lr 来源码；服务器保存 lr → project/pixel + agent + channel + content + site_origin 的映射。
- 目标网页例：https://your-product.example/?lr=x_AbCdEfGh123。也可由既有 /r/{code} 重定向到带来源参数的目标网页；重定向请求本身不是网站访问证据。
- 网站未安装像素时，链接不能自动产生网站事件。未带 lr 的访问仍可由已安装像素上报项目数据，记为未归因。

### 触点与校验

- SDK 上报像素、匿名访客、会话、事件编号及来源码；服务器核对像素归属、项目与目标网站后创建独立 touchpoint_id。
- 不信任客户端自填的 Agent、渠道或内容信息。lr 是公开来源标记，不是后端鉴权凭据；关键业务回传使用网站后端独立密钥。
- 同一访客、同一会话可有多个推广触点。新的有效来源新增触点，不覆盖已有会话的首次来源，也不只覆盖一个 sessionStorage ref。
- 已验证触点在本站保存，站内跳转没有 lr 时沿用有效上下文；默认最近触点、30 天窗口，也可在高级设置切换首次触点或 7/14 天窗口。
- 新访客携带无效或其他项目的来源码时，不接受该归因声明，但保留当前项目的有效事件为未归因。
- 跨域场景须显式传递并重新校验，不依赖跨站共享浏览器存储。代码样例尚不是已实现的 SDK/API 契约。

### 注册、订单与异步回传

- 注册/登录时关联匿名访客和项目用户编号。
- 注册或创建订单时，等待 SDK 初始化与来源校验完成，读取已验证的归因上下文并提交给业务后端，保存到用户/订单。异常超时不应导致业务事件丢失，应按明确策略保留并处理待归因/未归因状态。
- 异步支付回调读取订单保存的触点、用户及访客上下文，不读取回调当时浏览器的最新来源。
- 归因有效性按业务实际发生时间与触点窗口核验，不因延迟接收而混淆业务时间和接收时间。
- 事件按 event_id 去重；注册按 user_id；有效使用按用户及规则版本；购买按 order_id，付费人数再按 user_id。核心行为定义变更时，正式实现需生成规则版本。
- 先接收合法项目事件，再计算推广归因；不因找不到推广来源而拒绝整个业务事件。
