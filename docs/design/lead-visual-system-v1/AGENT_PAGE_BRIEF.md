# lead Agent 页面重新设计简报

本轮范围是高保真视觉设计、视觉规则和交互规格，不应用产品代码。用户已指定 Huly 的氛围、Raycast 的色彩表现和 Linear 的界面秩序；并要求降低社媒启停权重、优化字重字号与间距。设计输入沿用本聊天已确认的业务定位和八项功能要求。

## 目标与验收

用户无需派发每日任务，即可知道 Agent 是否在自动运营、哪些账号已连接、带来了什么结果，并在需要时直接调整业务和运营偏好。界面阅读顺序为状态、获客效果、偏好、记录及用量；对话在右侧辅助。

高保真主图为完整页面捕获，不能把其高度理解为实际首屏必须同时容纳全部模块。图片只表达视觉方向，具体字号、色值、状态和交互以 DESIGN.md 为准。

## 八项要求的落点

| 要求 | 页面与交互 |
| --- | --- |
| 所有社媒图标、连接状态、独立启停 | 一行或换行社媒栏；连接用品牌色、未连接灰色；点击具体账号展开启动/暂停面板 |
| 获客效果与网站像素 | 效果为主模块；只展示可计量的访问、点击、发布和转化；安装代码在该模块就近内联展开 |
| 低权重实时工作记录 | 默认三条，每条有社媒图标、动作和时间，完整历史按需展开 |
| 右侧贯穿的辅助聊天 | 独立消息滚动和底部输入，不承担主导航和每日派工 |
| 可编辑的业务与运营偏好 | 直接展示、原位编辑；保留用户设定与 Agent 完善的来源 |
| 直接展示高级摘要 | Tokens、当前额度、浏览器时长、预估费用状态；明细按需展开 |
| 编辑头像和名称 | 默认原创像素头像；名称默认项目名，用户显式编辑后保留 |
| 改善账号连接交互 | 平台进度、专属浏览器、直接输入/粘贴/滚轮、完成验证；浏览器输入独立于工作台刷新 |

## 状态与数据

| 状态 | 必须呈现的内容 |
| --- | --- |
| 新 Agent | 可编辑身份、空业务偏好、灰色社媒图标；效果区就近提供接入入口，不造假曲线 |
| 已连接但未运营 | 品牌色图标和已连接状态，可在具体账号管理中启动 |
| 运营中 | 状态点、实际最新行为及已计量效果，不要求用户留在聊天 |
| 单平台暂停 | 该图标仍保留品牌色，暂停状态另示，其余平台状态独立 |
| 重新登录或失败 | 异常就近显示文字与处理入口；不能只有一个红点 |
| 数据未接入或过期 | 指标显示空值、覆盖和最近接收时间；访问与服务端转化分别说明 |
| 偏好编辑 | 原位保存/取消、保留草稿、并发更新反馈；Agent 更新不能覆盖用户未保存的内容 |
| 用量缺价格或仅部分计价 | 显示暂无法估算或明确未计价范围，不伪装为完整费用 |
| 只读成员 | 仍能阅读业务与运营结果；编辑和连接不可执行且有明确状态 |
| 页面加载与重连 | 内容骨架保留位置；失败在原区域重试，不清空整个工作台 |

图中 128、214、396、24 和用量均为示例，统一标注。实现必须从真实接口读取；发布累计口径和访问时间窗口需分别标记。费用必须有模型用量与价格依据。实际连接操作、第三方登录、真实发布和性能验收均不在本轮图片生成范围。

## 操作边界

查看型页面没有必须强行安排的主操作。需要接入网站或重新登录时，在对应模块显出主操作；状态正常时，连接、编辑、管理和更多保持中性。所有关键操作除聊天外都有直接入口。

桌面锚定账号面板约 280–320px，显示平台、账号名、连接状态、运营状态、单平台开关和重新登录。实际浏览器接管使用更大区域，具有退出、验证和明确焦点返回。接管与账号验证分开，不把打开窗口当作登录成功。

## 模块分区修订 1.1

用户进一步指出模块紧邻、分割和递进不足。本轮把独立模块边界设为直接验收项：紧凑社媒面板、完整且稍亮的效果主面板、两块独立偏好面板、全宽工作记录面板和全宽用量摘要，按重要性顺序展开。

主区画布边距 40px；面板内边距 28–32px；独立模块之间露出 32–40px 画布，主组之间留出 48–56px。面板采用低色度底色、1px 中性全边界与 12px 圆角，不给模块里的每项指标或每行记录继续套框。高度随内容增长，保留自然滚动；对话继续是低权重右栏。

验收时缩小图片观察：必须能先辨认效果主区，再辨认配置与辅助信息的不同区域。不能只有一页密集文本和若干细线，也不能让各模块成为同尺寸、同强调度的重复卡片。

## 尚待确认的设计结果

本轮规范和主图作为同一设计提案交付。确认视觉方向后，再以本规范约束产品代码、响应式适配和真实操作验证。现有 PRODUCT.md / DESIGN.md 中“聊天优先、暖灰草绿、深藏高级项”的旧方向，不作为本轮界面的验收依据。
